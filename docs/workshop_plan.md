# 1 天企业 Agent 实战 Workshop 流程

目标：让参与者通过 5 个 Lab 完成一个从可靠输入到受控 Agent 的最小闭环。建议 12–24 人，两人一组；讲师与助教各一名。

| 时间 | 环节 | 内容与产出 |
|---|---|---|
| 09:00–09:20 | 开场与基线 | 目标、边界、安全约定；运行环境自检；收集每组业务问题 |
| 09:20–10:10 | Lab 01 Prompt | zero-shot / few-shot / 步骤化推理；练习：为客服分类设计 prompt contract，并写回归样例 |
| 10:10–10:20 | 休息 | 助教处理环境问题 |
| 10:20–11:10 | Lab 02 Structured Output | JSON Schema、Pydantic 思维、失败重试；练习：把工单字段接入下游接口并拒绝额外字段 |
| 11:10–11:35 | Q&A / 复盘 | 比较提示词与接口契约；讨论 Claude / GPT 公平评测方法 |
| 11:35–12:00 | 小组挑战 1 | 为自选场景定义输入、输出、异常与验收集 |
| 12:00–13:00 | 午休 | 不安排必做任务 |
| 13:00–14:00 | Lab 03 Tool Calling | 三个工具、白名单、参数与错误处理；练习：组合计算器与天气，并模拟超时 |
| 14:00–15:00 | Lab 04 RAG | 分块、embedding、检索、引用、拒答；练习：加入政策文档，验证有证据回答和无证据拒答 |
| 15:00–15:15 | 休息 | 保存代码，运行阶段测试 |
| 15:15–16:15 | Lab 05 Agent Loop | ReAct / Plan-and-Execute、trace、max steps、guardrails；练习：实现受控多步任务并统计工具覆盖率 |
| 16:15–16:45 | 综合挑战 | 各组选一个场景，画出 Prompt → Schema → Tool/RAG → Loop 的最小架构与风险清单 |
| 16:45–17:10 | 展示与同伴评审 | 每组 3 分钟演示；按正确性、可观察性、安全边界打分 |
| 17:10–17:30 | Q&A 与行动项 | 跑全量 pytest；形成 30 天 PoC 计划、负责人和停止条件 |

## 五道核心练习题

1. **Prompt**：将模糊的“判断客户情绪”改成含角色、标签、约束、示例和回归集的接口。
2. **Structured Output**：设计工单 Schema，分别构造合法、缺字段、错类型和多字段样例。
3. **Tool Calling**：为三个工具定义调用边界，统一包装未知工具、非法参数与超时错误。
4. **RAG**：对同一文档尝试两组分块参数，比较召回并让答案强制带来源；无证据必须拒答。
5. **Agent Loop**：让 Agent 完成两步任务，限制最大步数，禁止敏感工具，并报告覆盖率、步骤数和错误数。

## 课前与课后

课前 2 天确认 Python 版本、网络限制、是否允许外部模型以及客户数据禁入规则。课后交付测试结果、架构草图、风险清单与 PoC 行动项；不把课堂代码直接声明为生产系统。

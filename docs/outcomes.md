# 预期学习产出

完成训练后，参与者能够：

1. 将业务需求改写为包含任务、约束、示例与输出格式的 prompt contract。
2. 使用 JSON Schema / Pydantic 思维定义结构化数据，并测试缺字段、错类型和额外字段。
3. 解释 function calling 的安全边界，注册白名单工具并统一处理执行错误。
4. 实现教学版 RAG：分块、向量表示、检索、引用和无证据拒答。
5. 阅读 ReAct / Plan-and-Execute trace，为 Agent 添加最大步数、工具限制和停止条件。
6. 使用 pytest 建立回归基线，以正确性、覆盖率、错误率和成本讨论评测。
7. 为企业 PoC 输出最小架构、数据边界、风险清单与下一步行动。

## 不包含的承诺

一天训练不等于生产上线，不替代安全、隐私、合规、容量与供应商评审；不保证特定模型准确率或业务收益。验收以代码可运行、测试可复现、边界可说明为准。
